# `@repo/prettier-config`

Shared [Prettier](https://prettier.io/) code formatting configurations for the Scryme monorepo workspace.

## 📦 Usage

To use this configuration in a package or application, reference it in your local `package.json` or `.prettierrc.json`:

### `package.json`
```json
{
  "prettier": "@repo/prettier-config"
}
```

### `.prettierrc.json`
```json
"@repo/prettier-config"
```
