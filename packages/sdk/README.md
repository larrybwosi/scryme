# `@repo/sdk`

The unified TypeScript SDK client library for the central Scryme platform services. It is utilized to provide typed interactions and API integration across various internal workspace nodes.

## 🚀 Key Features

- **Standardized Client Hooks**: Clean API wrappers mapping backend endpoints.
- **Pre-Configured Interceptors**: Intercepts outgoing requests to append authorization cookies and headers dynamically.
- **Fail-Safe Response Mappings**: Parses standard REST errors and wraps responses safely for frontend usage.
